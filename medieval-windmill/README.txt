CONTENTS
288 animation PNGs and 8 static rotations. Every PNG is 256 x 256 with transparency.
Gentle Wind Rotation: S 20, SE 18, SW 18 frames.
Construction: S 32, SE 40, SW 40 frames.
Destruction: S 40, SE 40, SW 40 frames.
Static rotations: N, NE, E, SE, S, SW, W, NW.
Only S, SE and SW have animation. The other views are static.

USAGE
Import PNGs as sprites with transparency enabled. Keep a consistent canvas origin/pivot across each sequence. Play frames in filename order. Start around 12 FPS and adjust to your game. Loop Gentle Wind Rotation. Play Construction and Destruction once, then hold the final frame as appropriate.
Use nearest-neighbor/point filtering to preserve pixel edges. PNG files are supplied unchanged from the source; no engine-specific setup is included.

No terrain, interiors, modular tileset, game engine project, audio or gameplay code is included.
