# ASSETS

A working collection of 2D pixel-art asset packs gathered for game projects
by Relic & Ember Studios. 46 packs: tilesets, buildings, characters, VFX, props.

## ⚠️ Read this first

**Nothing in this repository is original art by me.** Every folder is a
third-party asset pack, mostly from Itch.io, and each pack remains the
property of its creator under that creator's own license.

- These packs are here for development and prototyping of our games.
- Each pack's license (see the `license.txt` / `README.txt` inside the pack
  folder, where provided) governs how it may be used.
- Typically that means: fine to use inside a game (including commercially),
  **not** fine to redistribute or resell the raw assets.
- If you like a pack, don't take it from here — go get it from the creator
  and support them. They give this stuff away.
